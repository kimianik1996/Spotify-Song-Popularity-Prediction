# Spotify-Song-Popularity-Prediction
This project analyzed spotify dataset to predict future popular songs based on other features like danceability and genres with a dataset of over 10,000 songs across 125 genres. It includes data cleaning, feature engineering, visualization, model building, and evaluation using Python.

## 📁 Project Structure
EDA_Process_Code ==> Jupyter notebooks for data exploration, plots, and visuals for analysis and presentation. 

[open in Colab] https://drive.google.com/file/d/141EqLFRgocoyuwaCNP0l7UaUukOlo1jc/view?usp=sharing



Data_Models_Code ==> Jupyter notebooks for preprocession and model building. it includes 3 models. 

[open in Colab] https://drive.google.com/file/d/1MfQMPLMtg_vEp7ATOywlRwv0NFL4miXr/view?usp=sharing


Dataset ==> spotify_cleaned_fixed_dataset.csv "cleaned dataset" 

Business presenation.pptx ==> display results and outcomes of the project. 

## 🔧 Tools Used

- Python (Pandas, Scikit-learn, Matplotlib, Seaborn, XGBoost)
- Jupyter Notebook
- SMOTE (imbalanced-learn)

## 📈 Results

The Voting classifier model trained with SMOTE achieved an 0.8166 accuracy score in predicting whether a song will become popular or not.
